Now the real work: ask each site for its page. A site can be slow, down for a
second, or down for good. The program has to wait a limited time, try again
when a failure may pass, and never let one site stop the others.

## Check one site, then all of them

Create `check.js`:

```js title="check.js"
const nc = require("@ix-xs/node-comfort");

async function checkSite(site, config) {
  try {
    const response = await nc.http.get(site.url, {
      timeout: config.TIMEOUT,
      retry: { attempts: 3, delay: "300ms" },
      responseType: "text",
    });
    return { name: site.name, up: true, status: response.status, attempts: response.attempts };
  } catch (error) {
    return { name: site.name, up: false, status: error.status ?? 0, error: error.message };
  }
}

function checkAll(sites, config) {
  return nc.async.map(sites, (site) => checkSite(site, config), { concurrency: config.CONCURRENCY });
}

module.exports = { checkAll };
```

| Option | Why |
| --- | --- |
| `timeout` | a site that never answers fails after `TIMEOUT` instead of blocking the check |
| `retry` | 3 attempts in all, 300 ms then 600 ms apart |
| `responseType: "text"` | the page is read as text: an HTML page is not JSON |
| `concurrency` | at most `CONCURRENCY` requests at the same time |

`nc.http.get()` throws when the answer is not a success: a status outside
2xx, a network error, a timeout. The `catch` turns that into a result, so one
site down doesn't stop the others. `nc.async.map()` returns the results in
the order of the sites, whatever order they finish in.

Only failures that may pass are retried: network errors, timeouts, and the
statuses 408, 413, 429, 500, 502, 503 and 504. A `404` is not: asking again gives
the same answer.

## Print the results

Replace `status.js`:

```js title="status.js" ins={4,9,11-16}
const nc = require("@ix-xs/node-comfort");
const { loadConfig } = require("./config");
const { loadSites } = require("./sites");
const { checkAll } = require("./check");

async function main() {
  const config = loadConfig();
  const sites = loadSites(config.SITES_FILE);
  nc.info(`Checking ${sites.length} sites`);

  const results = await checkAll(sites, config);
  for (const result of results) {
    if (!result.up) nc.error(`${result.name} is down: ${result.error}`);
    else if (result.attempts > 1) nc.warn(`${result.name} is up, after ${result.attempts} attempts`);
    else nc.success(`${result.name} is up`);
  }
}

main().catch((error) => {
  nc.error(error.message);
  process.exitCode = 1;
});
```
