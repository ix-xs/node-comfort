## Create the folder

```bash
mkdir status
cd status
npm init -y
npm install @ix-xs/node-comfort
```

`npm init -y` writes `package.json`, which describes the project.
`npm install` adds node-comfort to it, and to `node_modules/`.

## Write the first script

```js title="status.js"
const nc = require("@ix-xs/node-comfort");

nc.info("Starting the status check");
nc.success("node-comfort works");
nc.warn("There is no site to check yet");
```

The program tells you what it does through the logger, which you will use on
every page. It needs no setup:

| Call | Badge | Goes to |
| --- | --- | --- |
| `nc.info()` | `ℹ INFO` | stdout |
| `nc.success()` | `✔ OK` | stdout |
| `nc.warn()` | `⚠ WARN` | stderr |
| `nc.error()` | `✖ ERROR` | stderr |

- **Why the time:** when the program runs for hours, you know when each line
  happened.
- **Why two outputs:** warnings and errors go to stderr, so that
  `node status.js > out.txt` keeps them on screen.
- **Why no colors in a file:** colors are for a terminal. Redirected to a
  file, the same lines are plain text.

`LOG_LEVEL=warn` hides `info` and `success`, and `LOG_LEVEL=silent` hides
everything. The [logger page](/essentials/logger/) has the rest.
