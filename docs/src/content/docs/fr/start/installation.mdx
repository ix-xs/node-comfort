node-comfort est un seul paquet, sans dépendance. Il lui faut seulement un
Node.js récent.

## Installer Node.js

Node.js exécute du JavaScript hors du navigateur. Installez la version **LTS**
depuis [nodejs.org](https://nodejs.org), puis vérifiez la version :

<TerminalDemo scene="start/installation/version" />

| Branche de Node.js | Version minimale |
| --- | --- |
| Node.js 22 | 22.23.4 |
| Node.js 24 | 24.22.1 |
| Node.js 26 | 26.12.1 |

Les versions plus anciennes [peuvent être plantées par une réponse HTTP malveillante](/system/http/#servers-you-dont-control),
et Node.js 23 et 25 ne sont pas pris en charge. Node.js 26 est le choix le plus
rapide : les fuseaux horaires y passent par `Temporal`.

## Installer le paquet

Dans le dossier de votre projet :

```bash
npm install @ix-xs/node-comfort
```

Rien d'autre n'est installé avec lui, et rien ne s'exécute à l'installation.

## Lancer un premier script

Créez `hello.js` :

```js title="hello.js"
const nc = require("@ix-xs/node-comfort");

nc.info("Hello from node-comfort");
nc.success(nc.str.slugify("Héllo Wörld, from node-comfort!"));
nc.box(nc.time.format(new Date(), "dddd D MMMM YYYY"), { title: "today" });
```

<TerminalDemo scene="start/installation/hello" />

| Ligne | Ce qu'elle fait |
| --- | --- |
| `require("@ix-xs/node-comfort")` | charge le paquet ; tous les outils sont rangés dans `nc` |
| `nc.info()`, `nc.success()` | écrivent une ligne de log, avec l'heure et un badge |
| `nc.str.slugify()` | transforme un titre en morceau d'URL |
| `nc.box()` | dessine un cadre autour d'un texte |

La sortie est en couleur dans un terminal, et en texte brut quand vous la
redirigez vers un fichier.

## CommonJS, modules ES et TypeScript

Le paquet fonctionne de la même façon partout. Le guide utilise CommonJS.

```js
// CommonJS
const nc = require("@ix-xs/node-comfort");
const { str, isEmail } = require("@ix-xs/node-comfort");
```

```js
// Modules ES
import nc from "@ix-xs/node-comfort";
import { str, isEmail, nc as toolkit } from "@ix-xs/node-comfort";
```

```ts
// TypeScript : les types sont fournis avec le paquet
import nc = require("@ix-xs/node-comfort");
import { schema as s, type Infer } from "@ix-xs/node-comfort";
```

Toute la boîte à outils est aussi exportée sous les noms `nc` et
`nodeComfort` : `const { nc } = require("@ix-xs/node-comfort")` fonctionne
donc aussi.

## Charger un seul espace de noms

Chaque espace de noms a son propre point d'entrée :

```js
import { slugify, truncate } from "@ix-xs/node-comfort/str";
import SQLite from "@ix-xs/node-comfort/sqlite";
const { get, set } = require("@ix-xs/node-comfort/obj");
```

En modules ES, cela ne charge que ce que vous utilisez : Node.js lit tous les
exports du paquet racine quand vous l'importez. Les chiffres se trouvent sur la
page [Performances](/help/performance/).

Les points d'entrée sont `logger`, `fs`, `checker`, `utils`, `str`, `num`,
`arr`, `obj`, `func`, `time`, `id`, `crypto`, `color`, `cli`, `sys`, `async`,
`schema`, `http`, `env`, `errors`, `sqlite`, `cache` et `emitter`.

## Les variables qui changent le comportement

| Variable | Effet |
| --- | --- |
| `LOG_LEVEL` | Niveau de log minimal : `trace`, `debug`, `info`, `warn`, `error`, `fatal` ou `silent` |
| `LOG_FORMAT=json` | Les logs deviennent un objet JSON par ligne |
| `DEBUG` | Affiche les logs `debug` : `DEBUG=1` pour tous, `DEBUG=db,http:*` pour les loggers qui ont ces portées |
| `NO_COLOR` | Désactive les couleurs |
| `FORCE_COLOR=1\|2\|3` | Force les couleurs, en 16, 256 ou 16 millions de couleurs |
| `NODE_COMFORT_DOTENV=false` | Ne charge pas `.env` au chargement du paquet ([en savoir plus](/project/configuration/#write-the-env-file)) |
