node-comfort is one package with no dependencies. All it needs is a recent
Node.js.

## Install Node.js

Node.js runs JavaScript outside the browser. Install the **LTS** version from
[nodejs.org](https://nodejs.org), then check the version:

<TerminalDemo scene="start/installation/version" />

| Node.js line | Minimum version |
| --- | --- |
| Node.js 22 | 22.23.4 |
| Node.js 24 | 24.22.1 |
| Node.js 26 | 26.12.1 |

Older versions [can be crashed by a malicious HTTP response](/system/http/#servers-you-dont-control),
and Node.js 23 and 25 are not supported. Node.js 26 is the fastest choice:
time zones go through `Temporal` there.

## Install the package

In the folder of your project:

```bash
npm install @ix-xs/node-comfort
```

Nothing else is installed with it, and nothing runs at install time.

## Run a first script

Create `hello.js`:

```js title="hello.js"
const nc = require("@ix-xs/node-comfort");

nc.info("Hello from node-comfort");
nc.success(nc.str.slugify("Héllo Wörld, from node-comfort!"));
nc.box(nc.time.format(new Date(), "dddd D MMMM YYYY"), { title: "today" });
```

<TerminalDemo scene="start/installation/hello" />

| Line | What it does |
| --- | --- |
| `require("@ix-xs/node-comfort")` | loads the package; every tool hangs off `nc` |
| `nc.info()`, `nc.success()` | write a log line, with the time and a badge |
| `nc.str.slugify()` | turns a title into a piece of URL |
| `nc.box()` | draws a frame around text |

The output has colors in a terminal, and is plain text when you redirect it to
a file.

## CommonJS, ES modules and TypeScript

The package works the same way everywhere. The guide uses CommonJS.

```js
// CommonJS
const nc = require("@ix-xs/node-comfort");
const { str, isEmail } = require("@ix-xs/node-comfort");
```

```js
// ES modules
import nc from "@ix-xs/node-comfort";
import { str, isEmail, nc as toolkit } from "@ix-xs/node-comfort";
```

```ts
// TypeScript: types come with the package
import nc = require("@ix-xs/node-comfort");
import { schema as s, type Infer } from "@ix-xs/node-comfort";
```

The whole toolkit is also exported as `nc` and `nodeComfort`, so
`const { nc } = require("@ix-xs/node-comfort")` works too.

## Loading one namespace

Each namespace has its own entry point:

```js
import { slugify, truncate } from "@ix-xs/node-comfort/str";
import SQLite from "@ix-xs/node-comfort/sqlite";
const { get, set } = require("@ix-xs/node-comfort/obj");
```

In ES modules, this loads only what you use: Node.js reads every export of the
root package when you import it. [Performance](/help/performance/) has the
numbers.

The entry points are `logger`, `fs`, `checker`, `utils`, `str`, `num`, `arr`,
`obj`, `func`, `time`, `id`, `crypto`, `color`, `cli`, `sys`, `async`,
`schema`, `http`, `env`, `errors`, `sqlite`, `cache` and `emitter`.

## Variables that change the behavior

| Variable | Effect |
| --- | --- |
| `LOG_LEVEL` | Minimum log level: `trace`, `debug`, `info`, `warn`, `error`, `fatal` or `silent` |
| `LOG_FORMAT=json` | Logs become one JSON object per line |
| `DEBUG` | Shows `debug` logs: `DEBUG=1` for all of them, `DEBUG=db,http:*` for the loggers with these scopes |
| `NO_COLOR` | Turns colors off |
| `FORCE_COLOR=1\|2\|3` | Forces colors on, with 16, 256 or 16 million colors |
| `NODE_COMFORT_DOTENV=false` | Doesn't load `.env` when the package loads ([more](/project/configuration/#write-the-env-file)) |
