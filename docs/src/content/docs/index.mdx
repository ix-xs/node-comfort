<section class="nc-section">
  <header data-reveal>
    <span>Why it holds up</span>
    <h2>Small promises, kept</h2>
  </header>
  <ul class="nc-points">
    <li data-reveal><h3>Nothing to audit but this</h3><p>Zero runtime dependencies. One package to review, one version to pin, one changelog to read. Nothing arrives in your <code>node_modules</code> that you did not ask for.</p></li>
    <li data-reveal><h3>You pay for what you touch</h3><p><code>require("@ix-xs/node-comfort")</code> takes about 3 ms. Each namespace loads the first time you use it, and can be imported on its own.</p></li>
    <li data-reveal><h3>Your editor knows everything</h3><p>Written in JavaScript with complete JSDoc, shipped with generated declarations. Completions, documentation on hover and inferred types, in plain JS as in TypeScript.</p></li>
    <li data-reveal><h3>Safe by default</h3><p>Atomic writes, constant-time comparisons, bounded password hashing, object helpers that ignore <code>__proto__</code>, retries that never repeat a POST.</p></li>
    <li data-reveal><h3>Honest about failure</h3><p>Functions that can fail in normal life return <code>undefined</code> or <code>false</code>. Those that fail because something is wrong throw an error with a <code>code</code> and the context you need.</p></li>
    <li data-reveal><h3>Tested where you run it</h3><p>Four hundred tests on Windows, macOS and Linux, from Node 22.13 to the latest, and every example of this site is run before it is published.</p></li>
  </ul>
</section>
